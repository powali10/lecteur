# Lecteur — Bilingual Reader FR↔ES

Lector bilingüe francés-español con audio sincronizado y anotaciones gramaticales.
Construido para Fer. Lee, escucha y aprende fránces con libros reales.

## Cómo funciona

1. Abres `index.html`
2. Seleccionas un libro
3. Ves dos columnas: original francés | traducción español
4. Presionas Play → el audio avanza y la frase actual se resalta
5. Clic en cualquier palabra → traducción + pronunciación + nota gramatical

## Stack

- HTML + CSS + JS puro (sin frameworks)
- GitHub Pages para hosting → [https://powali10.github.io/lecteur/](https://powali10.github.io/lecteur/)
- Web Speech API (TTS nativo del navegador, voz francesa)
- Datos alineados FR-ES con anotaciones gramaticales por frase
